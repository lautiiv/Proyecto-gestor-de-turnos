Sistema de gestión de turnos para estudios de resonancia magnética.

El sistema se divide en dos módulos principales

Menu pacientes👤:
- Crear paciente
- Modificar paciente
- Eliminar paciente
- Mostrar un paciente por ID
- Mostrar todos los pacientes

Menu turnos🗓️:
- Registrar turno
- Modificar turno:
  - Cancelar turno
  - Reprogramar turno
  - Cambiar equipo
- Ver turnos de un paciente por "id_paciente"
- Ver un turno por "id_turno"
- Mostrar turnos por día:
  - Permite usar la fecha actual o ingresar una manual
  - Los turnos se muestran ordenados cronológicamente
  - Se agrupan por resonador

 Tecnologias:
 -Python
 -MySQL
 -Pytest
 -mysql-connector
